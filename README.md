# ICT Gems App

Handy-App für den Live-Abgleich: Passt das Chartbild zu einem Konzept aus meiner ICT Gems Bibliothek? Abgleich-Werkzeug, kein Signalgeber.

**Installieren (Android):** Seite in Chrome öffnen → Menü ⋮ → „App installieren“. Läuft danach offline.

Wird aus dem Obsidian-Vault erzeugt (`Trading/ICT Gems Bibliothek/App/gems_app_build.py`) – nicht hier von Hand ändern.
